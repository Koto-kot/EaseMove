# MVP Scope

## MVP Free

### Головна
- карта тіла front/back;
- великі tappable hotspots;
- швидкі входи: За комп’ютером, У ліжку, Очі.

### Каталог вправ
- 3 великі картки приблизно у видимій зоні;
- вертикальний scroll;
- preview;
- назва;
- короткий опис;
- `Почати`.

### Exercise player
- велика анімація/послідовність кадрів;
- реальний elapsed time;
- progress до рекомендованої послідовності;
- `← Попередня`;
- `Старт / Пауза / Продовжити`;
- `Стоп`;
- `Наступна →`;
- 5-секундний countdown при ручному Start;
- музика;
- голосові команди;
- Stop у будь-який момент.

### Auto-flow
- штатне завершення;
- +1 до lifetime counter;
- preview наступної вправи;
- 10 секунд повного відпочинку;
- auto-start на 0;
- ручний Previous/Next скасовує auto-mode;
- вибрана вручну вправа запускається тільки через Start + 5 с countdown.

### Дані
- локальне збереження;
- lifetime exercises;
- фактичний час;
- early stop;
- pauses;
- source collection.

### Нагадування
- opt-in;
- звук;
- вібрація;
- без текстової мотиваційної нотифікації як обов’язкової частини.

### Мова
- automatic;
- ручний вибір;
- fallback English;
- MVP content authoring: Ukrainian;
- система одразу мульти-мовна.

## Не входить у перший code slice

- акаунти;
- cloud sync;
- AI;
- human curator;
- health-device integrations;
- камера/pose tracking;
- автоматичне вимірювання ROM;
- автоматичне клінічне дозування.
