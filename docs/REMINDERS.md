# Reminders

## Free

- opt-in;
- вибір часу;
- звук on/off;
- вібрація on/off;
- мінімум текстового навантаження.

Продуктова ідея: нагадування може бути лише приємним звуком + vibration без мотиваційного тексту.

## Pro

- кілька нагадувань;
- різні дні;
- робочі дні;
- персональні набори;
- розумніші графіки.

## Safety / UX

- не використовувати shame/guilt;
- не створювати надмірну частоту;
- у quiet hours не турбувати;
- дозвіл на notifications запитувати контекстно, а не одразу при install.
