# Menu & Navigation

> **Застаріло в частині нижньої навігації.** Затверджений домашній екран
> (`docs/ui/home/HOME_SCREEN_LAYOUT_SPEC.md`, `DECISIONS.md` 46) не має
> нижнього таб-бару в MVP: ситуації відкриваються картками 2x2 на головній,
> «Моя активність» — з drawer. Решта цього документа (правила меню, шляхи
> навігації, заборона на приховування керування плеєра) чинна.

## Основна навігація

1. **Тіло**
2. **За комп’ютером**
3. **У ліжку**
4. **Очі**

На звичайних browse-екранах доступ може бути через bottom navigation або інший постійний compact navigation.

На активному Exercise Player основна нижня навігація ховається, щоб не конкурувати з:
`Previous / Start-Pause / Stop / Next`.

Вихід — через системний Back або Home/Close, визначений у UI.

## Тіло

Карта тіла веде в зони. Початковий порядок бібліотеки зверху вниз:

- Шия
- Плечі
- Верхня частина спини
- Лікті
- Кисті / зап’ястя
- Поперек
- Таз / стегна
- Коліна
- Гомілки
- Гомілковостопні суглоби
- Стопи

Точний набір hotspot можна коригувати без зміни Exercise Engine.

Натискання → contextual paywall, не silent failure.

## Contextual paywall

Paywall пояснює саме ту функцію, на яку натиснули, і показує доступні плани.
Не показувати агресивний paywall одразу після відкриття застосунку.
