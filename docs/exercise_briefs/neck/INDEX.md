## Repository note

`NECK_002` in this repository is the exercise that used to be `NECK_001`:
same movement as the pack's `seated_head_turn_left_right`, but with the
repository's own text, its NHS sources and its dosing of three cycles with a
five-second hold on each side. It runs 51 seconds rather than 61, and it is
the library's only `repeat_cycles` exercise. See `docs/DECISIONS.md` 70-72.
